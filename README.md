# さなる個別 @will 冬のまなび案内 2026

`冬期講座提案アプリ.html` を開くと、インストールやサーバー起動なしで使えます。

1. 学年・校舎形態→教科を選び、「この教科のプランを比較する」で候補を並べます。教科別の生徒情報は表示条件を変えても保持されます。
2. 候補を仮選択し、「確認して提案書へ」で講座別の条件・単元・教材を確認します。保護者への文章・料金もここで整えます。
3. 「この冬に学ぶ意義」のチェックを入れ、「まとめてPDFを作成」を押します。
4. 完成したPDFを確認し、「PDFを保存」を押します。

PDFは印刷画面を経由せず、アプリ内で直接生成します。雪景色・書体・A4の余白を固定し、提案書と講座別資料を1ファイルにまとめます。標準サンプルは提案書2ページ＋算数・国語の意義各1ページの計4ページです。長文や多数の講座では続きのページを追加します。料金の未入力や条件未確認を「確認中」として保持し、社員用メモは出力しません。絵文字など同梱フォントにない文字は、欠落させず変更をお願いするエラーを表示します。

日本語フォントを同梱しているため、単体HTMLは約31MB、出力PDFは約12MBあります。アプリの起動・PDF作成時にネット接続は不要です。PDFの表示に対応しないアプリ内ブラウザーでも、保存してPDF閲覧ソフトで確認できます。

## サンプル

- `samples/アプリ読込用サンプル.json`：提案書の「編集用ファイルを開く」で読込。現在の編集内容は先に保存してください。
- `samples/アプリ出力_保護者向けサンプル.pdf`：アプリと同じPDF生成処理で出力した見本。

サンプルは架空の小5生徒で、算数強化8回・国語補強8回を選択しています。

## 開発・検証

`dist/` が分割ソースです。`python build-local.py` で単体HTMLを再作成します。通常の更新では既存の `dist/pdf-assets.js` をそのまま使用できます。

`npm install` 後、`npm test` で講座・推薦ロジック・DOM・PDF生成を検証します。PDF検証は `output/pdf/` に見本と長文テストを生成します。実行時はPDFと同じJavaScriptエンジンを使い、4ページ構成、長文の改ページ、料金、個別編集、社員用メモの除外、作成ボタンからの導線を確認します。PDFを画像化し、日本語の描画も目視確認済みです。ブラウザー内蔵PDFビューアの表示は端末に依存します。

## 同梱ライブラリ・素材

- pdf-lib 1.17.1（MIT）：https://pdf-lib.js.org/
- @pdf-lib/fontkit 1.1.1（MIT）：https://github.com/Hopding/fontkit
- Noto Sans JP / Noto Serif JP（SIL OFL 1.1）：https://github.com/google/fonts

ライセンス・配布元READMEを `dist/vendor/` に同梱しています。Notoフォントは固定ウェイトへ変換し、全日本語文字を含めてPDFに埋め込みます。フォント変換は `prepare-fonts.py`、画像とフォントの同梱データ作成は `build-pdf-assets.py`（開発用 fonttools/Pillow が必要）です。元フォントはGoogle Fontsの上記配布元から取得できます。

講座データは提供された2026冬期講座最終確定Excelを基にしています。元Excelは変更していません。価格・日程は担当校舎で確認して入力してください。

## 選定画面の改修（2026-10-22）

生徒情報を共通情報と教科別情報に分離し、表示フィルターによる上書きを廃止しました。選択一覧はPC右側・スマートフォン下部の折りたたみで操作できます。合計は授業枠数であり、原文の回・コマ表記を講座ごとに残します。

確認事項は選択講座にだけ表示します。中3社会のテーマ重複、高1数学の受講目安・担当教師判断、高2数学の単元・レベル・必要コマ数、中1・中2数学の登録単元を記録できます。未確認でも仮選択・PDF作成は可能ですが、条件確認中と明示します。正式な料金・日程・単元別コマ数は推測せず校舎で確認してください。

保存形式はv3。v2の提案文・金額・共通メモを保持して読み込めます。旧共通の状況・履修記録は「共通情報」に残し、各教科へ自動配分しません。講座確認は未確認から始まります。

`verify-selection.cjs` は入力保持・教科往復・構造化確認・校舎変更・旧データ移行・実際の保存／編集ファイル入出力・学年変更を検査します。`verify-workbook.py` は提供Excelの5シート／61講座との照合と原本ハッシュを検査します。
